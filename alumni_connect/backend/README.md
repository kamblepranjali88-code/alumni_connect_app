# Alumni Connect Backend API

## Features Implemented
- ✅ Student registration with college database verification
- ✅ Email credentials via Nodemailer
- ✅ Login with UserID (STU_rollnumber format)
- ✅ First login password change
- ✅ Student profile view/edit
- ✅ JWT authentication ready
- ✅ Supabase integration

## Tech Stack
- Node.js + Express
- Supabase (PostgreSQL)
- Nodemailer
- Bcrypt for password hashing
